# Belajar AI
Proyek ini dibuat untuk belajar dasar Artificial Intelligence menggunakan Python, scikit-learn, dan berbagai tools AI lainnya.

## Struktur
- `main.py`: Script utama.
- `data/`: Dataset mentah atau bersih.
- `models/`: Model yang telah disimpan.
- `notebooks/`: Jupyter notebook untuk eksperimen.
